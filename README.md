# Customer Purchase Behavior Analysis & Prediction

##  Project Overview

This project focuses on analyzing customer transactional data to understand **purchasing behavior, product preferences, and repeat sales patterns**. The project combines **Python, SQL, Power BI, and Machine Learning** to transform raw customer data into actionable business insights and predictive outcomes.

The workflow includes data cleaning and preprocessing, exploratory analysis, SQL-based data analysis, interactive Power BI visualization, and a **Random Forest classification model** to predict customer purchasing behavior and support targeted marketing strategies.

##  Business Objective

The primary objectives of this project are to:

* Understand customer purchasing patterns across different product categories.
* Identify factors influencing customer buying behavior.
* Analyze repeat-purchase patterns.
* Build interactive dashboards for business decision-making.
* Predict customer purchasing behavior using Machine Learning.
* Support targeted marketing and customer-retention strategies.

##  Technologies Used

* **Python** – Data cleaning, preprocessing, analysis, and Machine Learning
* **Pandas & NumPy** – Data manipulation and preprocessing
* **Scikit-learn** – Machine Learning model development and evaluation
* **SQL** – Data querying, transformation, and analysis
* **Power BI** – Interactive dashboards and business visualization
* **Random Forest** – Customer behavior classification

##  Project Workflow

### 1. Data Collection & Understanding

The raw customer transactional dataset was examined to understand its structure, variables, customer information, transaction details, and purchasing patterns.

### 2. Data Cleaning & Preprocessing

Python was used to prepare the dataset for analysis and modeling. This included:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Cleaning inconsistent data
* Preparing relevant features for analysis and modeling

### 3. Exploratory Data Analysis

Customer transactions were analyzed to identify:

* Popular product categories
* Customer purchasing patterns
* Purchase frequency
* Repeat sales behavior
* Category-wise sales trends
* Customer-level purchasing characteristics

### 4. SQL Analysis

SQL was used to structure and analyze the cleaned data efficiently. Queries were developed to extract meaningful business information and identify customer and product-level patterns.

### 5. Power BI Dashboard

An interactive Power BI dashboard was developed to present the analytical findings in a business-friendly format.

The dashboard enables users to analyze:

* Sales performance
* Product category trends
* Customer purchasing behavior
* Repeat purchases
* Category-wise performance
* Key business metrics

### 6. Machine Learning Model

A **Random Forest Classifier** was trained to predict customer purchasing behavior and repeat sales.

Random Forest is an ensemble learning technique that combines multiple decision trees and uses their collective predictions to improve robustness and reduce overfitting compared with a single decision tree.

### 7. Model Evaluation

The classification model was evaluated using appropriate classification metrics to assess its predictive performance.

Key evaluation measures include:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

The model achieved strong evaluation performance, demonstrating its potential for identifying customers with specific purchasing behavior.

##  Key Insights

The analysis helps businesses understand:

* Which product categories contribute most to customer purchases.
* How customer purchasing patterns vary across categories.
* Which customers are more likely to make repeat purchases.
* Patterns that can be used for customer segmentation.
* How predictive analytics can support targeted marketing campaigns.

##  Business Impact

The combination of descriptive analytics and predictive modeling can help businesses:

* Improve customer targeting.
* Identify potential repeat customers.
* Design personalized marketing campaigns.
* Improve customer retention.
* Make data-driven marketing decisions.
* Optimize promotional strategies across product categories.
